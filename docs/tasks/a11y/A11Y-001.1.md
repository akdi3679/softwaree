## OBJECTIVE
Run axe-core on every PR. Block if a critical a11y issue is detected.

## REQUIRED IMPLEMENTATION

Add to `apps/admin/package.json`:
```json
"devDependencies": {
  "@axe-core/playwright": "^4.10.0",
  "playwright": "^1.47.0"
}
```

Create `product/apps/admin/tests/a11y.spec.ts`:

```typescript
import { test, expect } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

test.describe('A11y - Admin pages', () => {
  for (const page of ['/', '/projects', '/users', '/audit', '/modules', '/backup']) {
    test(`${page} has no critical a11y issues`, async ({ page: p }) => {
      await p.goto(page);
      const accessibilityScanResults = await new AxeBuilder({ page: p })
        .withTags(['wcag2a', 'wcag2aa', 'wcag21a', 'wcag21aa'])
        .analyze();
      const critical = accessibilityScanResults.violations.filter((v) => v.impact === 'critical');
      expect(critical, JSON.stringify(critical, null, 2)).toEqual([]);
    });
  }
});
```

Add to `package.json`:
```json
"scripts": {
  "test:a11y": "playwright test"
}
```
