## OBJECTIVE
Configure Prometheus to scrape Admin + Cloud metrics; add a Grafana dashboard.

## REQUIRED IMPLEMENTATION

Create `/workspace/internal-infra/prometheus/prometheus.yml`:

```yaml
global:
  scrape_interval: 30s
  evaluation_interval: 30s

scrape_configs:
  - job_name: 'cloud'
    static_configs:
      - targets: ['cloud-internal:8787']
    metrics_path: /metrics

  - job_name: 'admin'
    # Admin devices are discovered via our WireGuard mesh
    dns_sd_configs:
      - names: ['_prometheus._tcp.product.local']
        type: A
        port: 9090

rule_files:
  - alerts.yml
```

Create `/workspace/internal-infra/prometheus/alerts.yml`:

```yaml
groups:
  - name: admin
    rules:
      - alert: AdminDown
        expr: up{job="admin"} == 0
        for: 5m
        labels: { severity: critical }
        annotations:
          summary: "Admin device {{ $labels.instance }} is down"
      - alert: AdminHighMemory
        expr: process_resident_memory_bytes{job="admin"} > 2 * 1024 * 1024 * 1024
        for: 10m
        labels: { severity: warning }
      - alert: AdminSyncClientsZero
        expr: admin_sync_clients_active == 0
        for: 1h
        labels: { severity: info }
        annotations:
          summary: "Admin {{ $labels.instance }} has no active Users for 1h"
```

Create `/workspace/internal-infra/grafana/dashboards/admin.json` (skeleton, key panels):

```json
{
  "title": "Product Admin",
  "schemaVersion": 38,
  "panels": [
    {
      "title": "Commands per second",
      "type": "graph",
      "targets": [
        { "expr": "rate(admin_commands_total[1m])" }
      ]
    },
    {
      "title": "Events appended per second",
      "type": "graph",
      "targets": [
        { "expr": "rate(admin_events_appended_total[1m])" }
      ]
    },
    {
      "title": "Active sync clients",
      "type": "stat",
      "targets": [
        { "expr": "admin_sync_clients_active" }
      ]
    },
    {
      "title": "Module load p99",
      "type": "graph",
      "targets": [
        { "expr": "histogram_quantile(0.99, rate(admin_module_load_seconds_bucket[5m]))" }
      ]
    }
  ]
}
```
