Create `/workspace/docs/modules/TUTORIAL.md`:

# Module tutorial: build a "Hello, World" module

This walks through building, signing, and publishing a module.

## Step 1: Set up

```bash
cargo new --lib hello-module
cd hello-module
```

## Step 2: Add the SDK

```toml
# Cargo.toml
[lib]
crate-type = ["cdylib"]

[dependencies]
product-module-sdk = { path = "../../packages/module-sdk" }
```

## Step 3: Implement the handler

```rust
// src/lib.rs
use product_module_sdk::command::{Command, CommandOutcome};
use product_module_sdk::query::{Query, QueryOutcome};
use product_module_sdk::ModuleResult;

pub fn handle_command(cmd: Command) -> ModuleResult<CommandOutcome> {
    Ok(CommandOutcome {
        events: vec![],
        response: serde_json::json!({ "hello": "world", "input": cmd.payload }),
    })
}

pub fn handle_query(q: Query) -> ModuleResult<QueryOutcome> {
    Ok(QueryOutcome { response: serde_json::json!({ "version": env!("CARGO_PKG_VERSION") }) })
}
```

## Step 4: Build

```bash
rustup target add wasm32-wasip2
cargo build --target wasm32-wasip2 --release
```

Output: `target/wasm32-wasip2/release/hello_module.wasm`

## Step 5: Publish to the Cloud

```bash
product-publisher-cli publish \
  --manifest ./manifest.json \
  --binary ./target/wasm32-wasip2/release/hello_module.wasm
```

## Step 6: Install in your project

In the Admin: **Modules → Available → hello-module → Install**.

```markdown
# Module cookbook

Common patterns for module authors.

## Read a projection

```rust
let patients = read_projection("patients", "active").await?;
```

## Emit multiple events

```rust
return Ok(CommandOutcome {
    events: vec![event1, event2, event3],
    response: json!({ "count": 3 }),
});
```

## Validate a complex payload

Use serde:

```rust
#[derive(Deserialize)]
struct CreatePatient { full_name: String, phone: String, date_of_birth: String }

let req: CreatePatient = serde_json::from_value(cmd.payload)?;
```

## Return an error

```rust
return Err(ModuleError::Validation("full_name is required".into()));
```

## Use the host clock

```rust
let now = host::now_iso8601().await?;
```

## Generate a unique ID

```rust
let id = host::uuid_v7().await?;
```

## Write to the audit log

```rust
host::write_audit("patient.created", "patient", &id, "details").await?;
```

## What you cannot do

- Make network calls
- Read files outside your sandbox
- Fork
- Talk to other modules

If you need these, file a request on the publisher dashboard.
```
