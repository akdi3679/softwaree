## REQUIRED IMPLEMENTATION

Create `product/modules/retail-pos/Cargo.toml`:

```toml
[package]
name = "retail-pos"
version = "0.1.0"
edition = "2021"
description = "Retail POS: products, sales, receipts"

[lib]
crate-type = ["cdylib"]

[dependencies]
product-module-sdk = { path = "../../packages/module-sdk" }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
chrono = { version = "0.4", features = ["serde"] }

```

Create `product/modules/retail-pos/src/lib.rs`:

```rust
mod commands;
mod queries;

use product_module_sdk::command::{Command, CommandOutcome};
use product_module_sdk::query::{Query, QueryOutcome};
use product_module_sdk::{ModuleError, ModuleResult};

pub fn handle_command(cmd: Command) -> ModuleResult<CommandOutcome> {
    match cmd.command_type.as_str() {
        "product.create" => commands::product::handle_create(&cmd),
        "sale.record" => commands::sale::handle_record(&cmd),
        "sale.refund" => commands::sale::handle_refund(&cmd),
        _ => Err(ModuleError::Validation(format!("unknown: {}", cmd.command_type))),
    }
}

pub fn handle_query(q: Query) -> ModuleResult<QueryOutcome> {
    match q.query_type.as_str() {
        "product.list" => queries::product::handle_list(&q),
        "sale.today" => queries::sale::handle_today(&q),
        _ => Err(ModuleError::Validation(format!("unknown: {}", q.query_type))),
    }
}
```

Create similar for `gym` and `school` modules (members/classes/checkins, students/classes/attendance).
